# odin-recipes

This is my Odin Recipes project from The Odin Project Foundations course.

About the Project

The goal of this project is to build a recipe website using HTML. The website will contain links to different recipes, images, headings, paragraphs, and lists.

Skills I Will Learn

- Creating HTML pages
- Adding links and images
- Using headings and paragraphs
- Creating ordered and unordered lists
- Organizing files and folders
- Using Git and GitHub
